# LLM Chatbot for Human-Computer Interaction

## Project Overview

This project demonstrates a conversational chatbot developed using Python, Hugging Face Transformers, Gradio, and Google Colab.

The chatbot accepts natural language questions and generates AI-based responses using a pre-trained Large Language Model (LLM).

## Technologies Used

- Python
- Hugging Face Transformers
- Gradio
- Torch
- Google Colab

## Installation

Install the required libraries:

pip install gradio transformers torch

## Running the Application

1. Open the notebook in Google Colab.
2. Execute all cells in sequence.
3. Wait for the model to load.
4. Launch the Gradio interface.
5. Open the generated public URL.
6. Start interacting with the chatbot.

## Sample Questions

- What is Artificial Intelligence?
- Explain Machine Learning.
- What is Human-Computer Interaction?
- How does data analytics help business?

## Limitations

- Responses may not always be factually accurate.
- The chatbot does not verify information.
- Long-term conversation memory is not supported.
- Internet access is required.
