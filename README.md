# Development Environment Setup

This repository contains the development environment setup completed for the AI/HCI course. The objective of this exercise was to configure a working Python-based development environment and integrate it with a GitHub repository.

## Tools and Technologies Used
- Anaconda Distribution
- Jupyter Notebook
- Python
- GitHub

## Application Description
A simple Hello World Jupyter Notebook application was created to validate the development environment setup. The notebook demonstrates basic Python execution and confirms that the environment is functioning correctly.

## Repository Contents
- README.md: Overview of the project and setup
- hello_world.ipynb: Jupyter Notebook containing the Hello World program

## Purpose of the Project
The purpose of this project is to understand how to:
- Set up a development environment using Anaconda
- Work with Jupyter Notebook for code development
- Manage and store code using GitHub

## Notes
The development environment was configured locally using Anaconda, and the notebook was created and executed using Jupyter Notebook. The files were then uploaded to GitHub for version control and sharing.
